# Contributing

Thanks for your interest in unbraid.

unbraid is developed by one person, and the project doesn't accept pull requests. Reviewing outside code for a
VPN app takes a lot of care, and with one author the licensing stays simple. You're still free to fork it under
the GPL.

You can help in other ways:

- Report bugs in the [issue tracker](https://github.com/quiet-crafts/unbraid/issues). Say which phone and Android
  version you use, which provider and protocol, and what you expected to happen. Leave out credentials and
  account details.
- Tell us when a provider changes something and unbraid stops connecting. These breakages are often the hardest
  to notice.
- Suggest improvements to the guides on [unbraid.app](https://unbraid.app).
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).

If you find unbraid useful, a [donation](https://unbraid.app/donate/) helps keep it going.
